In the original thesis, the author lists some 275 cognate sets with standardized meanings. These have been linked to Concepticon. However, the source data do not show these meanings in the same form, in fact, they show many more, but hardly normalized elicitation glosses. 

For this representation of the data, we decided to use the list of 275 cognate sets that are printed as such in the thesis. The data was as such extracted from the thesis and converted to tabulare formats (file `raw/cognates.tsv`).

From there, the CLDF conversion script conducts an automated comparison with the data accompanying the article (the data upon which the analysis was based in the first place).
